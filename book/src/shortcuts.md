# Keyboard shortcuts

Press **F1** in Solrac for the same list. On Windows and Linux, ⌘ is Ctrl.

| Key | Does |
| --- | --- |
| Tab | Hide or show the interface |
| Esc | Close the topmost window |
| ⌘, | Preferences |
| ⌘Q | Quit |
| ⌘N | New Game |
| ⌘L | Games Library |
| ⌘E | Engine Thinking |
| ⌘↑ / ⌘↓ | Engine Mind / back to the board |
| ⌘+ / ⌘− | Larger / smaller text |
| F | Flip the board |
| Z | Zoom to fit |
| R | Usual view |
| L | Show or hide labels |
| ← → Home End | Step through the move list |
| ↑ ↓ | Swap in variations |
| Space | Hold to talk |
